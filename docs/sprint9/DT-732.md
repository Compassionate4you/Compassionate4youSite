# DT-732 — Hospice section layout migration

Sprint: 9

## Changes

- Understanding Hospice Care and Going Above & Beyond for Every Family now render with HeaderStackSection and its stylesheet.
- Our 5-Step Hospice Care Process now renders with TimelineSection, TimelineSection.css, and the shared foundation styles. CMS step order, localized headings, and available descriptions are retained. Leading numeric prefixes such as `1. ` are removed from displayed step titles because the timeline supplies its own numbering; stored cards remain unchanged.
- Benefits and interdisciplinary team content render together under Hospice Care Team & Benefits using HeaderCardsSection and its stylesheet. Benefits appear first, followed by team cards; the combined section occupies the benefits position.
- The Hospice-only presentation adapter resolves current CMS card references and localized text, with the existing embedded-card fallback. CMS records are unchanged; no reseed or database migration is needed.
- Migrated sections no longer render legacy card-section/card-grid markup or use their CSS rules. Shared foundation styles remain supplied by the new components.
- Other sections still use DynamicSectionRenderer. If benefits are unassigned, the team remains visible independently with HeaderCardsSection.

## Files modified

- `client/src/pages/ContentPage.jsx`: select the Hospice adapter only for the Hospice page.
- `client/src/components/modular/HospiceSections.jsx`: resolve CMS items, combine benefits/team, and dispatch stack, cards, and timeline layouts.
- `client/src/components/modular/sections/__tests__/HospiceSections.test.jsx`: integration coverage for ordering, copy, fallback, unchanged stored data, and absence of legacy markup.
- `docs/sprint9/DT-732.md`: implementation and validation record.

Existing uncommitted layout/component changes in the workspace were preserved.

## Remaining legacy stylesheet consumers

`CardSection.css` remains imported by CardSection.jsx, which DynamicSectionRenderer uses for CARD_GRID and CARD_SECTION layouts. Remaining consumers include other pages' card grids and Welcome banner wrappers. The Hospice care-process section no longer uses legacy grid markup. Migrate the remaining consumers before removing the stylesheet and its import. This story does not delete it or duplicate its rules in the new stylesheets.

## Validation

- Focused Hospice integration and shared section-layout tests: 2 files, 18 tests passed, including five ordered timeline steps, localized copy, single numbering, unchanged CMS cards, and unrelated-section fallback.
- Production client build: passed, with dependency module-directive, dynamic-import, and bundle-size warnings.
- Standard checks on the new adapter and test: passed using a writable temporary cache directory.
- `git diff --check`: passed.
- Browser checks at desktop and mobile widths were not performed; responsive behavior uses the existing layout component styles unchanged.
